# Geocache-Helfer

Mobile Web-App für die Cache-Suche: GC-Code, Karte (OpenStreetMap), Kompass mit GPS, Multi-/Mystery-Formeln, Decoder (ROT13, Caesar, Vigenère, Morse …), Koordinaten-Tools und Favoriten.

- Eine einzige Datei: `index.html`, kein Build-Schritt
- Läuft über GitHub Pages (HTTPS ist nötig für GPS und Kompass)
- Favoriten werden lokal im Browser gespeichert (Export/Import als JSON im Favoriten-Tab)

## Hinweise
- iOS: Beim ersten Start „GPS & Kompass starten“ tippen und den Zugriff auf Bewegung & Ausrichtung erlauben.
- Android/Chrome: Standortfreigabe für die Seite erlauben.
